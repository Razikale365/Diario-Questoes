# Requirements - Milestone v1.3

## 1. Recursive Section Dragging [DRAG]

- **DRAG-01**: Dragging a Section Header must move the header itself and all "children" blocks associated with it.
- **DRAG-02**: "Children" are defined as blocks whose `lesson` field matches the Section Header's `title`.
- **DRAG-03**: During the drag, if matching blocks are scattered in the list, they should be "snapped" together physically at the new drop location.
- **DRAG-04**: Non-section blocks dragged individually retain their current single-unit behavior.

## 2. Smart Auto-Sections on Import [IMP]

- **IMP-01**: When importing a task (via file or paste), the system must automatically identify unique `lesson`/`aula` values.
- **IMP-02**: For each unique `lesson`, a Section Header block must be automatically inserted at the top of that group.
- **IMP-03**: Re-importing or merging should not create duplicate section headers if one already exists for that lesson name.

## 3. Isolated Section Deletion [DEL]

- **DEL-01**: Deleting a Section Header (block with `isSection: true`) must ONLY remove the header block.
- **DEL-02**: The associated "child" blocks must NOT be deleted. They become "loose" or adopt the previous section's hierarchy implicitly.

## 4. Fuse Behavior Refinement [FUSE]

- **FUSE-01**: When two activity blocks fuse (one dropped on another), a section header is created ONLY if they don't already belong to a section.
- **FUSE-02**: If blocks already belong to a section, the "Fuse" behavior is disabled to prevent nested sections.
